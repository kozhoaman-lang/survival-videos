# Night 4 — монтаж в CapCut (пошагово)

Инструкция к сценарию `night4-monster-friend.md`. Названия кнопок даю по-русски и по-английски в скобках: в разных версиях CapCut они немного отличаются.

---

## 1. Подготовка (один раз)

### Проект
- Новый проект → формат **16:9** (длинное видео). Для Shorts потом отдельный проект **9:16**.
- Внизу на дорожке — **фон** (скриншот Roblox). Котики и монстр — **сверху, как наложение** (Наложение / Overlay).

### Котики — убрать зелёный фон
1. Наложение (Overlay) → добавить клип котика.
2. Выделить клип → **Вырезать (Cutout)** → **Хромакей (Chroma key)**.
3. Пипеткой ткнуть в зелёный → **Интенсивность (Intensity)** ~ 15–25, **Тень (Shadow)** ~ 10, чтобы не было зелёной каймы.
4. Сделать так один раз, потом **копировать клип** (а не добавлять заново) — настройки сохранятся.

### Монстр — вырезать из скриншота `…/55`
Вариант А (быстрее): Наложение → картинка `…/55` → **Вырезать (Cutout)** → **Удалить фон (Auto removal / Remove background)**. Проверить, что крылья не обрезались.
Вариант Б (если CapCut режет плохо): вырезать монстра в любом бесплатном «remove background» сервисе, сохранить как **PNG** с прозрачным фоном и вставить PNG как наложение.

### Порядок слоёв (важно)
Чем выше дорожка — тем «ближе» к зрителю.
- Монстр, который **встаёт позади** ToxicCat → дорожка монстра **ниже** дорожки ToxicCat.
- Монстр, который **накрывает героя крыльями** / обнимает → дорожка монстра **выше** героя.
Порядок меняется перетаскиванием клипа на другую дорожку.

## 2. Движения — как делать

Всё делается **ключевыми кадрами (Keyframe, значок ромбика ◇)**: ставишь ромбик → двигаешь бегунок по времени → меняешь положение/размер → CapCut сам делает плавное движение между ними.

| Движение | Как сделать | Длительность |
|---|---|---|
| **Въезд в кадр** (слайд) | ◇ в начале — котик за краем экрана. ◇ через 0,5 с — котик на месте | 0,5 с |
| **Ходьба** | Анимация → Комбо (Combo) → «Покачивание» / «Wiggle» или «Bounce». Или вручную: 3–4 ◇ вверх-вниз на 10–20 пикселей | пока идёт |
| **Дрожит (холодно/страшно)** | Эффекты (Effects) → «Тряска» / **Shake** на клип котика, сила маленькая | 1–3 с |
| **Крик** | Клип «крик» + ◇ масштаб 100% → 130% за 0,3 с + эффект Shake на весь кадр | 0,5–1 с |
| **Выглядывает (peek)** | Поставить котика так, чтобы из-за края экрана была видна только половина. ◇ чуть внутрь — ◇ обратно | 1 с |
| **Убегает очень быстро** | ◇ на месте → ◇ через 0,2 с за краем экрана + Эффекты → «Размытие движения» (**Motion blur**) | 0,2–0,3 с |
| **Посмотреть в другую сторону** | Редактировать (Edit) → **Отразить (Mirror)** | мгновенно |
| **Монстр застрял в двери** | ◇ масштаб нормальный → ◇ сжать по ширине (снять галочку «равномерный масштаб» / Uniform scale) → ◇ обратно. Если на телефоне нет — просто уменьшить и потрясти | 1 с |
| **Монстр встаёт позади** | Монстр за ToxicCat (слой ниже). ◇ монстр внизу за кадром, маленький → ◇ через 1,5 с поднят и масштаб 120% | 1,5 с — медленно |
| **Монстр обнимает / укрывает крыльями** | Слой монстра **выше** героя. ◇ монстр рядом → ◇ монстр надвигается на героя, перекрывает его наполовину | 1 с |
| **Монстр ест (радуется)** | Анимация → Комбо → «Wiggle» / «Качание» | 2 с |
| **Монстр храпит** | ◇ масштаб 100% → 105% → 100% → 105% (дыхание) | пока спит |
| **Ночь / темнее** | Выделить фон → Настройка (Adjust) → Яркость (Brightness) −30…−50 | — |
| **Светящиеся глаза в темноте** | Текст «• •» белого цвета + Анимация «Мерцание» / Blink, или стикер «глаза» | 2 с |
| **Рыба переходит от героя к монстру** | Эмодзи 🐟 (текст или стикер), ◇ у героя → ◇ у монстра | 0,7 с |

Совет: не делай всё плавным. Котики-мемы смешнее, когда движения **резкие**: въехал → стоп → реакция.

## 3. Текст — двигается с котиком или нет?

Есть **два вида текста**:

### А. «Уведомления игры» — НЕ двигаются
Это `NIGHT 4`, `NIGHT 3 SURVIVED ✅`, `+1 FRIEND 🤝`, `TOXICCAT left the game 🏃💨`, `…the monster has a FAMILY 😳`.
- Стоят **на месте**, вверху экрана (или по центру для названия).
- Отдельная дорожка текста, ни к кому не привязан.
- Анимация появления: **«Появление» / Pop up** или **«Печатная машинка» / Typewriter**.

### Б. «Слова персонажа» — стоят над котиком
Это `TOXICCAT: "MY fire. go away."`, `TOXICCAT: "let's scare him 😈"`, `nom nom`, `zzz`, `*growl*`.
- Ставь текст **прямо над головой** нужного котика.
- Если котик в этот момент **стоит на месте** — просто поставь текст сверху, ничего не нужно.
- Если котик **двигается**, а текст должен ехать вместе с ним:
  - **CapCut на компьютере:** выделить клип котика + текст → правый клик → **Создать составной клип (Create compound clip)**. Теперь они двигаются вместе, ключевые кадры ставишь один раз на составной клип.
  - **CapCut на телефоне:** поставить на тексте **те же ключевые кадры в те же моменты**, что у котика (то же время, сдвиг на то же расстояние).
- Проще всего: **показывай слова, когда котик уже остановился**. Тогда ничего привязывать не надо. В сценарии почти все слова стоят как раз в такие моменты.

### Стиль текста (для всех)
- Шрифт жирный (любой «Bold»), **белый** с **чёрной обводкой** (Stroke / Обводка ~ 6–8).
- 1–5 слов на экране. Держать **минимум 1,5 с**, чтобы успели прочитать.
- Слова ToxicCat можно делать **красноватыми**, монстра — **фиолетовыми**: сразу понятно, кто «говорит».

## 4. Пример — сцена «Монстр встаёт позади ToxicCat» (2:44–2:55)

Дорожки сверху вниз:
1. Текст `TOXICCAT left the game 🏃💨` (появится в 2:55)
2. ToxicCat (клип `1120011128…133`, потом клип крика)
3. Монстр (PNG)
4. Герой
5. Фон — бункер `…/35`, яркость −40

| Время | Что делаем |
|---|---|
| 2:44 | Музыку выключить (разрезать аудио). Герой: **Отразить**, чтобы «смотрел» на ToxicCat. Текст не нужен |
| 2:46 | ToxicCat: **Отразить** (поворачивается назад) |
| 2:46 | Монстр: ◇ внизу, за кадром, масштаб 80% |
| 2:48 | Монстр: ◇ поднят над ToxicCat, масштаб 120%. Звук: рык |
| 2:52 | Заменить клип ToxicCat на клип крика. ◇ масштаб 100% → 130% за 0,3 с, эффект **Shake**. Звук: крик ×3 |
| 2:55 | ToxicCat: ◇ на месте → ◇ через 0,2 с за левым краем + **Motion blur**. Появляется текст-уведомление |

## 5. Звуки и музыка

- CapCut → Аудио (Audio) → **Звуковые эффекты (Sound effects)**: там есть scream, boom, record scratch, footsteps, snore, heartbeat, "bling"/level up, fail trombone.
- Музыка: Аудио → Музыка → искать «spooky», «cute», «sad violin». Используй только то, что есть в CapCut без значка «только для CapCut» / без ограничений для YouTube, или бесплатную музыку из YouTube Audio Library.
- Перед страшным моментом — **1 секунда тишины** (просто разрезать и удалить кусок музыки). Это самое сильное, что можно сделать звуком.

---

## 6. Проверка перед экспортом

- Нигде не осталось зелёной каймы вокруг котиков.
- Каждый текст висит ≥ 1,5 с.
- Первые 10 секунд: крик героя и крик монстра — без задержек.
- Экспорт: **1080p, 30 fps** (или 60).
- Из готового видео вырезать 3 Shorts (таймкоды есть в сценарии) → новый проект 9:16 → фон растянуть/обрезать, котиков сделать крупнее.
